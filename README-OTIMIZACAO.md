# ITech — versão otimizada

## Principais alterações
- Hero da home reescrito para comunicar benefício e serviço com mais clareza.
- CTA principal direcionando para WhatsApp.
- Nova faixa de diferenciais/benefícios.
- Cards de serviços com hover e hierarquia visual melhor.
- CTA final com navegação real para Contato.
- Botão flutuante de WhatsApp em todas as páginas.
- Header: botão “Fale Conosco” agora é um link funcional.
- Logo das páginas internas retorna para a Home.
- Formulário de contato migrado de PHP para Netlify Forms, compatível com hospedagem estática na Netlify.
- SEO: títulos, descriptions, robots, theme-color e Open Graph na Home.
- Criados robots.txt e sitemap.xml.
- Adicionados headers básicos de segurança.
- Melhorias de acessibilidade: focus-visible, aria-label e honeypot no formulário.
- Melhorias responsivas para celular.
- Melhorias de contraste, espaçamento, sombras, estados hover e microinterações.
- Respeito a prefers-reduced-motion.

## Observação
As imagens e a identidade visual original foram preservadas. A alteração foi feita como uma camada de otimização sobre o CSS existente, reduzindo o risco de quebrar as páginas atuais.

## V2 — Landing page comercial
- Home reorganizada para conversão: Hero → dores → serviços → benefícios → processo → CTA.
- Hero com proposta de valor clara e CTAs para WhatsApp e serviços.
- Seção de dores do cliente para aumentar identificação.
- Serviços apresentados como cards comerciais com links.
- Nova seção de benefícios/diferenciais.
- Processo em 4 etapas para reduzir fricção.
- CTA final de alta visibilidade.
- Nova camada visual responsiva, com efeitos e componentes CSS próprios.
- Conteúdo pensado para pequenas e médias empresas sem exagerar em promessas.
